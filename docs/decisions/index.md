# Architecture Decision Records

Las decisiones se conservan junto al dominio que las implementa para mantener
el contexto. Este índice centraliza su localización.

| Dominio | Decisiones |
|---|---|
| Event Processor | [decisions-adr.md](../platform/event-processor/decisions-adr.md) |
| Event State Service | [README.md](../platform/event-state-service/README.md) |
| CACF | [decisions-adr.md](../platform/cacf/decisions-adr.md) |
| Dashboards | [architecture.md](../platform/dashboards/architecture.md) |
| Git y publicación | [gobierno Git](../platform/git/README.md) |

Las nuevas decisiones deben incluir contexto, decisión, alternativas,
consecuencias, compatibilidad y plan de reversión. No se debe reutilizar un ADR
de otro dominio para justificar un contrato diferente.
